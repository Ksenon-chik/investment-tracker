# 1. Контекстная диаграмма системы

### смысл

показывает **место приложения во внешнем мире**.

```
┌──────────────┐
│  Пользователь│
│   (браузер)  │
└──────┬───────┘
       │ HTTP
       ▼
┌──────────────────────┐
│   Web-приложение     │
│  учёта инвест. сделок│
└──────┬───────────────┘
       │ SQL
       ▼
┌──────────────┐
│   База данных│
│    SQLite    │
└──────────────┘
```

# 2. Общая архитектура (уровни)

### ключевая диаграмма для курсовой

```
┌─────────────────────────────┐
│        Presentation         │
│   FastAPI + HTML/Jinja2     │
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│        Service layer        │
│  user_service / deal_service│
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│         Data layer          │
│     SQLAlchemy ORM          │
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│          Database           │
│           SQLite            │
└─────────────────────────────┘
```

**Название для курсовой:**

> Трёхуровневая архитектура веб-приложения.

# 3. ER-диаграмма базы данных

```
┌──────────────┐
│     users    │
├──────────────┤
│ id (PK)      │
│ email        │
│ hashed_pass  │
│ created_at   │
└──────┬───────┘
       │ 1
       │
       │
       │ N
┌──────▼────────┐
│     deals     │
├───────────────┤
│ id (PK)       │
│ user_id (FK)  │
│ asset         │
│ amount        │
│ price         │
│ deal_type     │
│ created_at    │
└───────────────┘
```

**Смысл:**  
один пользователь → много сделок (**1:N**).

---

# 4. Диаграмма последовательности

## создание сделки

```
Пользователь
    │
    │ POST /deals
    ▼
Router (FastAPI)
    │
    │ валидация DealCreate
    ▼
Service (create_deal)
    │
    │ add / commit
    ▼
Database (SQLite)
    │
    │ сохранённая запись
    ▼
Service → Router
    ▼
HTTP-ответ пользователю
```

# 5. Диаграмма компонентов проекта

```
app/
 ├─ routers/
 ├─ services/
 ├─ models/
 ├─ schemas/
 ├─ db/
 ├─ templates/
 └─ static/
```

**Логика зависимостей:**

```
routers → services → models → database
schemas → routers & services
```
