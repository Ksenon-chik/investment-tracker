### 1. tradermake.money

### Реализованные функции

- Регистрация и авторизация пользователя
    
- Личный кабинет пользователя
    
- Ручное добавление сделок
    
- Хранение истории сделок
    
- Табличное представление сделок
    
- Базовая фильтрация сделок
    
- Расчет агрегированных показателей:
    
    - количество сделок
        
    - суммарная прибыль
        
    - суммарный убыток
        
    - процент прибыльных сделок
        
- Визуализация результатов торговли (графики)
    
- Дисклеймер об отсутствии инвестиционных рекомендаций
    

### Архитектурные и концептуальные особенности

- Минималистичный пользовательский интерфейс
    
- Отсутствие автоматического импорта сделок
    
- Аналитика носит описательный характер
    
- Сервис не взаимодействует с активами пользователя


### 2. tradersdiaries

### Общая характеристика

Сервис учета сделок с закрытой моделью доступа, ориентированный на постоянных пользователей. Основная функциональность скрыта за экраном авторизации.

### Реализованные функции (по доступной информации)

- Авторизация пользователя
    
- Учет торговых сделок
    
- Анализ торговой истории
    

### Концептуальные особенности

- Отсутствие публичного описания функционала
    
- Закрытый доступ без демонстрации возможностей
    
- Вероятное использование дополнительных параметров сделки (таймфреймы)
    

### Потенциально используемые идеи

- Использование таймфрейма сделки (M1, M5, H1, D1 и т.д.)
    
- Анализ сделок в разрезе временных интервалов


### 3. TradeZella

### Общая характеристика

Многофункциональная платформа для профессионального анализа торговой активности, ориентированная на автоматизацию и расширенную аналитику.

### Реализованные функции

- Авторизация и управление профилем пользователя
    
- Автоматический импорт сделок с торговых платформ
    
- Расширенная аналитика торговой активности
    
- Анализ сделок по различным срезам:
    
    - по активам
        
    - по временным периодам
        
    - по стратегиям
        
- Расчет продвинутых метрик
    
- Кумулятивные графики доходности
    
- Расширенная визуализация данных
    
- Масштабируемая архитектура
    

### Концептуальные особенности

- Четкое разделение данных, аналитики и визуализации
    
- Высокая степень автоматизации
    
- Ориентация на профессиональных пользователей


## Функции, включаемые в курсовую работу (MVP)

### Пользовательская часть

- Регистрация пользователя
    
- Авторизация и выход из системы
    
- Личный кабинет пользователя
    

### Учет сделок

- Ручное добавление сделки
    
- Редактирование и удаление сделки
    
- Хранение истории сделок
    
- Комментарий к сделке
    

### Структура сделки

- Дата сделки
    
- Актив
    
- Направление (покупка / продажа)
    
- Результат (прибыль / убыток)
    
- Величина результата
    
- Комментарий
    
- (опционально) Таймфрейм
    

### Просмотр и фильтрация

- Таблица сделок пользователя
    
- Фильтрация:
    
    - по дате
        
    - по активу
        
    - по результату (прибыль / убыток)
        

### Аналитика

- Общее количество сделок
    
- Суммарная прибыль
    
- Суммарный убыток
    
- Процент прибыльных сделок
    
- График изменения прибыли во времени
    

### Интерфейс

- Веб-интерфейс на HTML и CSS
    
- Простая визуализация графиков
    
- Минималистичный дизайн
    

### Юридический и академический аспект

- Дисклеймер об отсутствии инвестиционных рекомендаций
    
- Анализ исключительно исторических данных пользователя
