#### 1.1 управление учетной записью

- регистрация
- вход с помощью логина и пароля
- выход из системы
- редактирование профиля
#### 1.2 ограничения

- восстановление пароля

#### 1.3 личный кабинет

- информация о пользователе
- список добавления сделок
- аналитика

#### 2.1 учет инвестиционных сделок

- добавление сделок вручную
- просмотр списка всех сделок
- редактирование сделки
- удаление сделки

#### 2.2 Структура сделки:

- дата совершения сделки;
    
- финансовый актив;
    
- направление сделки (покупка / продажа);
    
- результат сделки (прибыль / убыток);
    
- величина прибыли или убытка + соотношение п/у;
    
- (опционально) комментарий пользователя;
    
- (опционально) таймфрейм сделки.

#### 2.3 Просмотр истории сделок

Пользователь может:

- просматривать полную историю своих сделок;
    
- сортировать сделки по дате;
    
- фильтровать сделки:
    
    - по дате;
        
    - по результату (прибыль / убыток + соотношение п/у).

#### 2.4 Аналитика и визуализация

Пользователю доступны следующие аналитические показатели:

- общее количество сделок;
    
- суммарная прибыль;
    
- суммарный убыток;
    
- процент прибыльных сделок;
    
- график изменения прибыли во времени.
    

Аналитика носит **описательный характер** и не содержит прогнозов.


### 3. Ограничения системы (курсовая работа)

#### 3.1 Ограничения по данным

- Все сделки добавляются **исключительно вручную**;
    
- Автоматический импорт данных с торговых платформ отсутствует;
    
- Система не хранит информацию о реальных активах пользователя;
    
- Все данные используются только для анализа истории сделок.

#### 3.2 Ограничения по аналитике

- Не выполняется прогнозирование рыночных данных;
    
- Не предоставляются торговые сигналы;
    
- Не рассчитываются сложные финансовые коэффициенты;
    
- Аналитика основана только на пользовательских данных.

#### 3.3 Ограничения по безопасности и ответственности

- Приложение не предоставляет инвестиционных, финансовых или юридических рекомендаций;
    
- Результаты анализа не могут служить основанием для принятия инвестиционных решений;
    
- Пользователь самостоятельно несет ответственность за интерпретацию данных.

### 4. Ограничения, снимаемые в рамках дипломной работы

В рамках дипломного проекта планируется расширение системы за счет:

- добавления автоматического импорта сделок;
    
- расширенной аналитики (добавление календаря сделок для общей картины);
    
- поддержки стратегий и таймфреймов;
    
- внедрения современного frontend-фреймворка;
    
- масштабирования архитектуры приложения.
